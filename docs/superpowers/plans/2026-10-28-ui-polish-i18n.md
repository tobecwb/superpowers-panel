# UI Polish + i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesenhar o painel superpowers em cartões coloridos e animados (módulo `Client`) e passar todo o texto exibido por um catálogo i18n com pt-BR e en.

**Architecture:** `register.tsx` continua dono dos átomos e de `$`; monta um `PanelModel` JSON já traduzido (`view-model.ts`) e o entrega a um `Client` (`panel.tsx`) que só desenha e anima com uma máquina de estados pura (`animation.ts`). Cliques voltam por `post` → `ui.message`. O `/sp status` usa o mesmo modelo via `text-view.ts`. O idioma vem de um catálogo tipado (`hooks/i18n/`) escolhido por `detectLocale`.

**Tech Stack:** TypeScript 5.9, Claude Code function hooks (`claude-code`, `claude-code/testing`), Bun, Biome 2.6, Knip 6.

**Spec:** `docs/superpowers/specs/2026-10-28-ui-polish-i18n-design.md`

## Global Constraints

- Convenções do `CLAUDE.md`: identificadores, comentários e descrições de teste em **inglês**; nada de abreviações de 1–3 letras (exceto `$`, `e`, `next`, índices); comentário só explica *por quê*; sem código morto; complexidade cognitiva ≤ 10; função com > 4 parâmetros recebe objeto; nunca `biome-ignore` nem afrouxar limites.
- Regras da engine: átomos declarados no arquivo que chama `read`/`update` (`register.tsx`); `$` só passado a funções de topo; `update` com o átomo escrito no ponto da chamada. O `Client` não recebe `$`.
- `module` do `Client` é literal de string no fonte: `module="./panel.tsx"`.
- Nenhum texto visível ao usuário fora de `hooks/i18n/` (exceto nomes de arquivo, slugs, assuntos de tarefa e nome cru de skill desconhecida). Pt-BR com acentos corretos.
- `en.ts` declarado `const en: Messages`; faltar chave quebra o `typecheck`.
- Sem dependências de runtime novas.
- Cores só por chaves do tema (`planMode`, `claude`, `permission`, `suggestion`, `error`, `warning`, `success`, `subtle`, `inverseText`).
- Animação: `TICK_MS = 80`; flash de conclusão 19 ticks (~1,5 s); pulso de borda 8 ticks (~0,6 s); easing da barra: metade da distância por tick, encaixa abaixo de 0,05.
- Ao fim de cada tarefa, `bun run check` passa (o pre-commit exige).

**User decisions (already made):**
- Foco principal: visual (cor, separação, vida); hierarquia e textos são secundários.
- Animação opção A: painel inteiro num `Client`, animando só o que comunica estado.
- Locale: `language` do Claude Code → `LANG` → `en`; `/sp lang pt-BR|en|auto` força e persiste.
- Layout "Cartões".
- Arquitetura A+A: view model serializável + catálogo tipado próprio.

## Review Focus

1. Painel estreito ou ainda sem layout (`surface.columns` 0 ou < 20): a barra não pode ter largura negativa nem quebrar; textos truncam. → teste em `barCells` (Task 2) e `ui.resize` (Task 3).
2. Plano ativo com `total = 0` (`tasks.json` ausente): nada de `NaN%`; barra vazia, `0/0 · 0%`. → testes em Task 1 e Task 2.
3. Fase de skill desconhecida (`onboard`, nome sem mapeamento): mostra o nome cru em tom `subtle`, sem quebrar. → teste em Task 1.
4. `language` em formatos variados (`"Português"`, `"pt_BR"`, `"English"`, `""`, não string) e `LANG=C.UTF-8`: escolha correta, padrão `en`. → testes em Task 0.
5. Plano selecionado que deixou de existir e mensagem malformada vinda do `Client`: sem cartão de detalhe, sem exceção. → testes em Task 1 e Task 3.

```ts
import { expect, test } from 'claude-code/testing'
import { detectLocale, messagesFor, parseLocaleChoice } from '../hooks/i18n'

const SAMPLE_ARGS = [2, 'T1'] as const

const collectStrings = (value: unknown): string[] => {
  if (typeof value === 'string') return [value]
  if (typeof value === 'function') return collectStrings((value as (...args: unknown[]) => unknown)(...SAMPLE_ARGS))
  if (typeof value === 'object' && value !== null) return Object.values(value).flatMap(collectStrings)
  return []
}

const keyPaths = (value: unknown, prefix = ''): string[] =>
  typeof value === 'object' && value !== null
    ? Object.entries(value).flatMap(([key, child]) => [`${prefix}${key}`, ...keyPaths(child, `${prefix}${key}.`)])
    : []

test('detectLocale prefers the forced choice', async () => {
  expect(detectLocale('en', 'Português', 'pt_BR.UTF-8')).toBe('en')
  expect(detectLocale('pt-BR', 'English', 'en_US.UTF-8')).toBe('pt-BR')
})

test('detectLocale reads the language setting in its many spellings', async () => {
  expect(detectLocale('auto', 'Portugues (PT-BR)', undefined)).toBe('pt-BR')
```

```ts
import type { Locale, LocaleChoice } from '../../types'
import { en } from './en'
import { type Messages, ptBR } from './pt-BR'

export type { Messages }

export const messagesFor = (locale: Locale): Messages => (locale === 'en' ? en : ptBR)

const normalize = (text: string): string =>
  text
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .trim()

const PORTUGUESE_TOKEN = /(^|[^a-z])pt([^a-z]|$)/

const isPortuguese = (text: string): boolean =>
  text.includes('portug') || text.startsWith('pt') || PORTUGUESE_TOKEN.test(text)

// The `language` setting is free text ("Portugues (PT-BR)", "English"): any non-empty value decides.
export const detectLocale = (choice: LocaleChoice, languageSetting: unknown, langEnv: string | undefined): Locale => {
  if (choice !== 'auto') return choice
  const setting = typeof languageSetting === 'string' ? normalize(languageSetting) : ''
  if (setting !== '') return isPortuguese(setting) ? 'pt-BR' : 'en'
  const lang = normalize(langEnv ?? '')
  return lang.startsWith('pt') ? 'pt-BR' : 'en'
}

export const parseLocaleChoice = (raw: string): LocaleChoice | undefined => {
  const text = normalize(raw)
  if (text === 'auto') return 'auto'
  if (text === 'en') return 'en'
  return text === 'pt' || text.replace('_', '-') === 'pt-br' ? 'pt-BR' : undefined
}
```

```ts
import { KIND_ICON, type PanelModel, type Row, type Section, type SectionItem } from './view-model'

const CELLS = 10

export const bar = (done: number, total: number): string => {
  const full = total === 0 ? 0 : Math.round((done / total) * CELLS)
  return '█'.repeat(full) + '░'.repeat(CELLS - full)
}

const withNote = (text: string, note: string | undefined): string => (note === undefined ? text : `${text}  ${note}`)

const rowText = (row: Row): string => withNote(`${KIND_ICON[row.kind]} ${row.text}`, row.note)

const block = (title: string, rows: readonly Row[]): string[] => (rows.length === 0 ? [] : ['', title, ...rows.map(rowText)])

const itemText = (item: SectionItem): string => withNote(`  · ${item.label}`, item.note)

const sectionText = (section: Section): string[] => [`${section.icon} ${section.header}`, ...section.items.map(itemText)]

const headerText = ({ header, labels }: PanelModel): string[] => {
  const lines = [`${labels.phase}: ${header.phase?.label ?? '—'}`]
  const plan = header.plan
  if (plan) lines.push(`${labels.plan}: ${plan.name}  ${bar(plan.done, plan.total)} ${plan.done}/${plan.total}`)
  if (header.syncWarning) lines.push(header.syncWarning)
  return lines
}

// Plain text of the same model the panel draws: `/sp status` and surfaces without `Client`.
export const textView = (model: PanelModel): string => {
  if (model.isEmpty) return model.labels.noData
  const projectLines = model.sections.length === 0 ? [model.labels.emptyProject] : model.sections.flatMap(sectionText)
  return [
    ...headerText(model),
    ...block(model.labels.now, model.now),
    ...block(model.labels.next, model.next),
    ...(model.done ? ['', `${KIND_ICON.done} ${model.done.label}`] : []),
    ...block(model.labels.outside, model.outside),
    '',
    model.labels.project,
    ...projectLines,
  ].join('\n')
}
```

```ts
import type { PanelModel, Row } from './view-model'

export const TICK_MS = 80

export const SPINNER = ['⠋', '⠙', '⠹', '⠸', '⠼', '⠴', '⠦', '⠧', '⠇', '⠏'] as const

// In ticks of TICK_MS: about 1.5 s of flash and 0.6 s of border pulse.
const FLASH_TICKS = 19
const PULSE_TICKS = 8
const SNAP_DISTANCE = 0.05

export type Flash = { row: Row; ticksLeft: number }

export type Motion = {
  model: PanelModel
  // The engine may hand an equal model as a new object: comparing the JSON keeps
  // `observe` from turning every redraw into a state change (a render loop).
  signature: string
  frame: number
  shownDone: number
  flashes: Flash[]
  pulseTicks: number
}

export const isSpinning = (model: PanelModel): boolean =>
  [...model.now, ...model.outside].some(row => row.kind === 'running')

const planName = (model: PanelModel): string | undefined => model.header.plan?.name

const doneOf = (model: PanelModel): number => model.header.plan?.done ?? 0

const completedFlashes = (previous: PanelModel, model: PanelModel): Flash[] => {
  const doneKeys = new Set(model.done?.keys ?? [])
  return [...previous.now, ...previous.next]
    .filter(row => doneKeys.has(row.key))
    .map(row => ({ row: { key: row.key, kind: 'done', text: row.text }, ticksLeft: FLASH_TICKS }))
}

export const observe = (previous: Motion | undefined, model: PanelModel): Motion => {
  const signature = JSON.stringify(model)
  if (previous === undefined) {
    return { model, signature, frame: 0, shownDone: doneOf(model), flashes: [], pulseTicks: 0 }
  }
  if (previous.signature === signature) return previous
  if (planName(previous.model) !== planName(model)) {
    const pulseTicks = planName(model) === undefined ? 0 : PULSE_TICKS
    return { ...previous, model, signature, shownDone: doneOf(model), flashes: [], pulseTicks }
  }
  return { ...previous, model, signature, flashes: [...previous.flashes, ...completedFlashes(previous.model, model)] }
}

const ease = (shown: number, target: number): number => {
  const gap = target - shown
  return Math.abs(gap) < SNAP_DISTANCE ? target : shown + gap / 2
}

export const step = (motion: Motion): Motion | undefined => {
  const target = doneOf(motion.model)
  const spinning = isSpinning(motion.model)
  const isIdle = !spinning && motion.shownDone === target && motion.flashes.length === 0 && motion.pulseTicks === 0
  if (isIdle) return undefined
  return {
    ...motion,
    frame: spinning ? (motion.frame + 1) % SPINNER.length : motion.frame,
    shownDone: ease(motion.shownDone, target),
    flashes: motion.flashes
      .map(flash => ({ ...flash, ticksLeft: flash.ticksLeft - 1 }))
      .filter(flash => flash.ticksLeft > 0),
    pulseTicks: Math.max(0, motion.pulseTicks - 1),
  }
}

export const barCells = (shownDone: number, total: number, cells: number): { filled: number; empty: number } => {
  const width = Math.max(0, Math.floor(cells))
  const ratio = total === 0 ? 0 : Math.min(1, Math.max(0, shownDone / total))
  const filled = Math.round(ratio * width)
  return { filled, empty: width - filled }
}

export const percent = (done: number, total: number): number => (total === 0 ? 0 : Math.round((done / total) * 100))
```

> Easing: de 1 para 3 o valor vai 2 → 2,5 → 2,75 → 2,875 → 2,9375 → 2,96875 → encaixa em 3 no 7º tick (≈ 560 ms). O teste `halfway` espera exatamente `2` após um tick.

```ts
export type PanelAction = { action: 'toggle' | 'select'; key: string }

// Posts come from the drawing thread as plain data: anything else is dropped.
export const parsePanelAction = (raw: unknown): PanelAction | undefined => {
  if (typeof raw !== 'object' || raw === null) return undefined
  const { action, key } = raw as Record<string, unknown>
  if (action !== 'toggle' && action !== 'select') return undefined
  return typeof key === 'string' ? { action, key } : undefined
}

export const toggleKey = (list: readonly string[], key: string): string[] =>
  list.includes(key) ? list.filter(expandedKey => expandedKey !== key) : [...list, key]
```

```tsx
export const Panel: ClientModule<JsonValue, Motion> = (props, surface) => {
  if (surface.state === undefined) {
    surface.every(TICK_MS, () => {
      const next = surface.state && step(surface.state)
      if (next) surface.setState(next)
    })
  }
  const motion = observe(surface.state, props as unknown as PanelModel)
  if (motion !== surface.state) surface.setState(motion)
  return panelView({
    elements: surface.elements,
    motion,
    columns: surface.columns || FALLBACK_COLUMNS,
    send: action => surface.post(action),
  })
}
```
